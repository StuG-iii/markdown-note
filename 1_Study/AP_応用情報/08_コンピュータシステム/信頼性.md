# 信頼性

## RASISとは

| 項目           | 日本語          | 意味                                           |
| -------------- | --------------- | ---------------------------------------------- |
| Reliability    | 信頼性          | 故障しにくいこと                               |
| Availability   | 可用性          | 使いたいときに使えること                       |
| Serviceability | 保守性          | 故障時に復旧・修理しやすいこと                 |
| Integrity      | 保全性 / 完全性 | データが正確で壊れたり改ざんされたりしないこと |
| Security       | 安全性 / 機密性 | 不正アクセスや情報漏えいを防げること           |

## R 信頼性

故障しにくいこと

### MTBF（平均故障間隔）

Mean Time Between Failures

一言：次に故障するまでの平均時間

あるサーバが平均して 1,000時間に1回故障するなら、
MTBF = 1,000時間

## S 保守性

早く復旧できること

### MTTR（平均復旧時間）

Mean Time To Repair

一言：故障してから復旧するまでの平均時間

故障してから平均して 2時間で復旧するなら、
MTTR = 2時間

## MTBFとMTTRのイメージ

正常稼働 ───────── 故障 ─ 修理 ─ 正常稼働 ───────── 故障 ─ 修理
          ← MTBF →       ←MTTR→           ← MTBF →     ←MTTR→

## A 可用性

稼働できていること

稼働率 = MTBF / (MTTR + MTBF)

### 稼働率例

稼働500時間 → 故障5時間 → 稼働3000時間 → 故障7時間

1750 / 1756 = 99.7%

### 全体の稼働率

例：
システムAの稼働率=99.7%
システムBの稼働率=99.7%

直列のシステムの場合
全体の稼働率 = 稼働率*稼働率

99.7 * 99.7 = 99.4%

並列のシステムの場合
A 稼働率=99.7%
  故障率=0.3%
B 稼働率=99.7%
  故障率=0.3%

全体の稼働率 = 1 - 両方停止する確率
全体の稼働率 = 1 - (故障率 *故障率)

0.3% = 0.003
両方停止 = 0.003 × 0.003 = 0.000009

全体稼働率 = 1 - 0.000009
           = 0.999991
           = 99.9991%
