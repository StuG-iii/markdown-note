# ハードウェアの性能計算

## 問題文の分解

1. 求める量
2. 量の意味
3. 基準となる単位
4. 量どうしの関係
5. 式
6. 単位確認

## ①最後に何を求めるのか？★

求めるものは次のように分類できる

| 求めるもの | 日本語での意味                      |
| ---------- | ----------------------------------- |
| 命令数     | 一定時間に何命令できるか            |
| 実行時間   | 処理が終わるまで何秒か              |
| 転送時間   | データを送り終わるまで何秒か        |
| 転送量     | 一定時間にどれだけ送れるか          |
| 平均時間   | 複数の場合を考慮した1回当たりの時間 |
| 使用率     | 全体のうち、どの程度使われているか  |
| 性能比     | 一方が他方の何倍か                  |

ここではまだ計算せず、

求めるもの：1秒当たりの命令数

のように書く

## ②求める量を「普通の日本語」に直す

MIPS
↓
1秒間に何百万命令できるか

命令実行時間
↓
1命令を終えるのに何秒かかるか

転送時間
↓
全部のデータを送り終えるまで何秒かかるか

## ③ 「全体」「1個当たり」「回数」に分ける★

全体量を求める：
全体量=1個当たり×個数

個数を求める：
個数=全体量÷1個当たり

1個当たりを求める
1個当たり=全体量÷個数

### CPUの場合

全体：1秒間のクロック数
1個当たり：1命令に必要なクロック数
個数：1秒間に実行できる命令数

したがって、
1秒間の命令数=1秒間のクロック数÷1命令当たりのクロック数

### データ転送の場合

全体：送るデータ量
1個当たり：1秒に送れるデータ量
個数：必要な秒数

したがって、
転送時間=データ量÷1秒当たりの転送量

## ④ 「どちら向きの量か」を確認する

性能計算では、似た数値でも向きが逆の量がある。

### 速さを表す量

命令 / 秒
bit / 秒
回 / 秒
クロック / 秒

「一定時間にどれだけできるか」

### 1回当たりを表す量

秒 / 命令
秒 / 回
クロック / 命令

「1個を処理するためにどれだけ必要か」

### 速さと1回あたりは逆数の関係

時間 / 命令 ←→ 命令 / 時間

例：
25ns / 命令

逆向きにすると

40,000,000命令 / 秒

## ⑤ 問題文を「一行の状況説明」にする★

例：1命令に25nsかかるCPUの性能を求める

→ 1秒という時間の中に、25nsの処理が何回入るか

→ 1秒÷25 ns/命令

例：1クロックが2nsで、1命令に5クロック必要

→ 2nsのクロックが5回分ある

→ 2 ns/クロック×5 クロック/命令

→ 10 ns/命令

## ⑥ 掛け算か割り算かを言葉から決める

### 掛け算になる場合

- 同じものが何回分ある
- 1個分を複数個集める
- ある割合分を取り出す

例：1クロック2nsが5クロック分ある
→ 2×5

### 割り算になる場合

- 全体に何個入るか
- 全体を一定量ずつ分ける
- 1個当たりを求める

例：1秒の中に25nsが何回入るか
→ 1秒÷25ns

例：6400Mbitを毎秒200Mbitずつ送る
→ 6400÷200

## ⑦ 単位をそろえてから計算する★

数値を計算する前に、単位だけを確認

例：

800 MB÷200 Mbps ← MBとMbitが一致していない

先に 800MB → 6400Mbit へ変換

## ⑧ 単位を消して式を検査する★

式が正しいか迷ったら、数値を無視して単位だけ計算する。

### CPU性能

クロック/秒 ÷ クロック/命令

→ クロック/秒 × 命令/クロック

→ 命令/秒 1秒間に実行できる命令数

### 命令実行時間

秒/クロック × クロック/命令

→ 秒/命令 1命令当たりの時間

### 転送時間

Mbit ÷ Mbit/秒

→ Mbit × 秒/Mbit

→ 秒

## ⑨ 桁と直感で答えを確認する

計算後は、答えの大小を確認する。

例：

- 1命令にかかる時間が短くなる
- 1秒当たりの命令数は多くなる

という関係がある。逆に

- CPIが大きくなる
- 1命令に多くのクロックが必要
- 1秒当たりの命令数は少なくなる

となるはず。したがって、

「CPIが4から8になったのにMIPSが増えた」なら計算方法が間違えている可能性がある。

```

```


## 5つの「型」

### 1. クロック時間

クロック時間 = 1 / クロック周波数

- 1GHz → 1ns
- 2GHz → 0.5ns
- 4GHz → 0.25ns

### 2. 命令実行時間

命令実行時間 = クロック時間 * CPI（１命令に必要な平均クロック数）

1秒間の命令数 = クロック周波数 / CPI

### 3. MIPS

```
MIPS = 1秒間の命令数 / 🔟^6
     = クロック周波数 / CPI / 10^6
```

2GHz、CPI=4の場合

```
2 * 10^9 / 4
= 0.5 * 10^9
= 500 + 10^6
```

### 4. メモリの実効アクセス時間

平均は「確率を掛けて足す」

実効アクセス時間
＝ 当たった場合 × ヒット率
＋ 外れた場合 × ミス率

キャッシュ：10ns
主記憶：100ns
ヒット率：90%

10 × 0.9 ＋ 100 × 0.1
＝ 9 ＋ 10
＝ 19ns

### 5. データ転送時間

転送時間
＝ データ量 ÷ 転送速度

100MB ÷ 20MB/秒 ＝ 5秒

1byte ＝ 8bit

100MBを100Mbpsで転送する場合、

100MB ＝ 800Mbit

800Mbit ÷ 100Mbit/秒
＝ 8秒

## 単位変換は計算と分離する

k ＝ 10^3
M ＝ 10^6
G ＝ 10^9

ms ＝ 10^-3秒
μs ＝ 10^-6秒
ns ＝ 10^-9秒

1byte ＝ 8bit

### 単位変換と数値計算を同時にしない

悪い例：
2GHz ÷ 4だから、たぶん500MIPS

良い例：
2GHz ＝ 2×10^9クロック/秒
2×10^9 ÷ 4
＝ 5×10^8命令/秒
＝ 500×10^6命令/秒
＝ 500MIPS
