# 計算問題公式一覧

## 信頼性・稼働率

| 分野             | 公式                                | 意味・使い方                         | 注釈・備考           |
| ---------------- | ----------------------------------- | ------------------------------------ | -------------------- |
| 稼働率           | **稼働率 = MTBF / (MTBF + MTTR)**   | システムが使える割合を求める         | 最重要公式の1つ      |
| MTBF             | **平均故障間隔**                    | 故障と故障の間の平均時間             | 長いほど良い         |
| MTTR             | **平均修復時間**                    | 故障してから復旧するまでの平均時間   | 短いほど良い         |
| 非稼働率         | **非稼働率 = MTTR / (MTBF + MTTR)** | 使えない割合                         | 稼働率とセットで出る |
| 直列構成の稼働率 | **全体 = 各装置の稼働率の積**       | 全部動かないとシステムが動かない場合 | 0.9×0.9 など         |
| 並列構成の稼働率 | **全体 = 1 - (各装置の停止率の積)** | どれか1つ動けばよい場合              | 冗長構成で頻出       |

## 性能・処理能力

| 分野         | 公式                                          | 意味・使い方                    | 注釈・備考                 |
| ------------ | --------------------------------------------- | ------------------------------- | -------------------------- |
| CPU実行時間  | **CPU実行時間 = 命令数 × CPI × クロック周期** | プログラム実行時間を求める      | CPIは1命令あたりクロック数 |
| クロック周期 | **クロック周期 = 1 / クロック周波数**         | 周波数から1クロック時間を求める | Hzの逆数                   |
| MIPS         | **MIPS = 命令実行数 / 実行時間 / 10^6**       | 1秒あたり何百万命令か           | 単純比較に使う             |
| FLOPS        | **FLOPS = 浮動小数点演算回数 / 秒**           | 科学技術計算向け性能指標        | GFLOPS, TFLOPS など        |
| スループット | **スループット = 単位時間あたり処理件数**     | どれだけ処理できるか            | 応答時間と別物             |
| 平均応答時間 | **平均応答時間 = 総応答時間 / 件数**          | 利用者視点の待ち時間平均        |                            |

## 伝送速度・通信量

| 分野              | 公式                                        | 意味・使い方             | 注釈・備考                 |
| ----------------- | ------------------------------------------- | ------------------------ | -------------------------- |
| 伝送時間          | **伝送時間 = データ量 / 伝送速度**          | 送信にかかる時間を求める | 単位を揃えることが最重要   |
| データ量          | **データ量 = 文字数 × 1文字あたりビット数** | 総ビット数を求める       | バイト→ビット変換注意      |
| ビット/バイト変換 | **1バイト = 8ビット**                       | 単位換算                 | 超頻出                     |
| KB換算            | **1KB = 1024B**                             | 容量換算                 | K=1000でなく1024扱いが基本 |
| MB換算            | **1MB = 1024KB**                            | 容量換算                 | 同上                       |
| bps               | **1秒あたりのビット数**                     | 回線速度の単位           | Byte/s と混同注意          |
| 通信量            | **通信量 = 1回分データ量 × 回数**           | 総トラフィックを求める   | 1日あたり計算などで出る    |

## 待ち行列

| 分野         | 公式                             | 意味・使い方                     | 注釈・備考                       |
| ------------ | -------------------------------- | -------------------------------- | -------------------------------- |
| 利用率       | **利用率 = 到着率 / サービス率** | 窓口やCPUの混み具合              | 1未満でないと破綻しやすい        |
| 平均待ち時間 | 問題条件に応じて計算             | 並びの長さや処理速度から求める   | 公式丸暗記より典型問題慣れが重要 |
| 平均系内人数 | 問題条件に応じて計算             | 待っている人数＋処理中人数       | Littleの法則が出ることもある     |
| Littleの法則 | **L = λW**                       | 系内人数 = 到着率 × 平均滞在時間 | 応用情報で出る可能性あり         |

## 情報理論

| 分野            | 公式                    | 意味・使い方   | 注釈・備考             |
| --------------- | ----------------------- | -------------- | ---------------------- |
| 情報量          | **I(x) = -log₂ P(x)**   | 事象xの情報量  | 起こりにくいほど大きい |
| 確率1/2の情報量 | **1ビット**             | よく出る基本値 |                        |
| 確率1/4の情報量 | **2ビット**             | よく出る基本値 |                        |
| 確率1/8の情報量 | **3ビット**             | よく出る基本値 |                        |
| エントロピー    | **H = -Σ P(i)log₂P(i)** | 平均情報量     | 出ても基本レベルが多い |

## 2進数・論理演算

| 分野               | 公式                      | 意味・使い方            | 注釈・備考 |
| ------------------ | ------------------------- | ----------------------- | ---------- |
| nビットの表現数    | **2^n 個**                | nビットで表せる通り数   |            |
| 符号なし整数最大値 | **2^n - 1**               | nビット符号なしの最大値 |            |
| 2の補数範囲        | **-2^(n-1) ～ 2^(n-1)-1** | 符号付き整数範囲        |            |
| 16進1桁            | **2進4桁に対応**          | 変換の基本              |            |
| 8進1桁             | **2進3桁に対応**          | 変換の基本              |            |
| AND                | **1∧1=1**                 | 両方1のときだけ1        |            |
| OR                 | **0∨0=0、それ以外1**      | どちらか1なら1          |            |
| XOR                | **異なれば1**             | 排他的論理和            |            |
| ド・モルガン       | **¬(A∧B)=¬A∨¬B**          | 論理式変形              | 逆も重要   |

## 確率・統計

| 分野     | 公式                                       | 意味・使い方     | 注釈・備考               |
| -------- | ------------------------------------------ | ---------------- | ------------------------ |
| 確率     | **確率 = 条件に合う場合の数 / 全場合の数** | 基本公式         |                          |
| 期待値   | **E = Σ(値 × 確率)**                       | 平均的見込み値   |                          |
| 平均     | **平均 = 合計 / 個数**                     | 基本統計量       |                          |
| 分散     | **分散 = Σ(偏差²) / 個数**                 | ばらつきの大きさ | 試験では概念レベルも多い |
| 標準偏差 | **標準偏差 = √分散**                       | 分散の平方根     |                          |

## プロジェクト管理（EVM）

| 分野 | 公式                   | 意味・使い方           | 注釈・備考                   |
| ---- | ---------------------- | ---------------------- | ---------------------------- |
| CV   | **CV = EV - AC**       | コスト差異             | マイナスなら予算超過         |
| SV   | **SV = EV - PV**       | 進捗差異               | マイナスなら遅れ             |
| CPI  | **CPI = EV / AC**      | コスト効率指数         | 1未満で悪化                  |
| SPI  | **SPI = EV / PV**      | 進捗効率指数           | 1未満で遅れ                  |
| BAC  | **総予算**             | 完了時予算             | 問題文で与えられることが多い |
| EAC  | **完了時総コスト見積** | 完了時にいくらかかるか | 問題によって式指定あり       |

## 経営計算

| 分野               | 公式                                 | 意味・使い方             | 注釈・備考               |
| ------------------ | ------------------------------------ | ------------------------ | ------------------------ |
| 限界利益           | **限界利益 = 売上高 - 変動費**       | 固定費回収に使える利益   |                          |
| 限界利益率         | **限界利益率 = 限界利益 / 売上高**   | 売上に対する限界利益割合 |                          |
| 損益分岐点売上高   | **固定費 / 限界利益率**              | 利益0になる売上高        | 超頻出                   |
| 損益分岐点販売量   | **固定費 / 1個当たり限界利益**       | 利益0の販売量            |                          |
| 利益               | **利益 = 売上高 - 費用**             | 基本式                   |                          |
| ROI                | **ROI = 利益 / 投資額 × 100**        | 投資効率                 | 問題により利益の定義確認 |
| 回収期間           | **投資額 / 年間回収額**              | 何年で回収できるか       | 単純回収法               |
| 減価償却（定額法） | **(取得原価 - 残存価額) / 耐用年数** | 毎年同額償却             | 基本だけ押さえる         |

## 工数・日程計算

| 分野         | 公式                                 | 意味・使い方           | 注釈・備考        |
| ------------ | ------------------------------------ | ---------------------- | ----------------- |
| 工数         | **工数 = 人数 × 日数（または時間）** | 作業量を表す           | 1人日、1人月など  |
| 必要日数     | **必要日数 = 工数 / 人数**           | 何日かかるか           |                   |
| 必要人数     | **必要人数 = 工数 / 日数**           | 何人必要か             |                   |
| 最早開始時刻 | PERTで前工程完了から算出             | 最も早く始められる時刻 |                   |
| 最遅開始時刻 | 納期から逆算                         | 遅らせられる限界       |                   |
| 余裕時間     | **最遅開始 - 最早開始**              | スラックとも呼ぶ       | 0ならクリティカル |

## 最重要

- 稼働率 = MTBF / (MTBF + MTTR)
- 伝送時間 = データ量 / 伝送速度
- 情報量 = -log₂P
- CV = EV - AC
- SV = EV - PV
- 限界利益 = 売上高 - 変動費
- 損益分岐点売上高 = 固定費 / 限界利益率
- ROI = 利益 / 投資額 × 100
- 工数 = 人数 × 時間
- nビットの表現数 = 2^n
