# 1. 企業会計とは？

企業の経済活動を数値で記録・報告する仕組み。

目的は3つ
1. 利害関係者（株主・債権者など）への報告
2. 経営判断のための情報提供
3. 税務計算の基礎

## 2. 財務三表

### 貸借対照表（B/S）

ある時点の財政状態

資産 ＝ 負債 ＋ 純資産

負債：返す義務のあるお金
資産：会社が持っているもの
純資産：自己資本（返さなくてよいお金）

### 損益計算書（P/L）

一定期間の経営成績

売上高
↓
売上総利益（粗利）
↓
営業利益
↓
経常利益
↓
当期純利益

営業利益＝本業の儲け
経常利益＝本業＋財務活動

### キャッシュフロー計算書（C/F）

お金の増減

区分は3つ
1. 営業活動CF
2. 投資活動CF
3. 財務活動CF

#### 頻出

黒字倒産の理由
→ 利益が出ても「現金」がないと倒産する

## 3. 費用と原価の違い

| 用語 | 意味                         |
| ---- | ---------------------------- |
| 原価 | 商品を作るためのコスト       |
| 費用 | 会計上、収益と対応させる支出 |

## 4. 減価償却（頻出）

固定資産を分割して費用化する仕組み。

減価償却費 = 取得価額 ÷ 耐用年数

## 5. 発生主義と現金主義

| 方式     | 基準             |
| -------- | ---------------- |
| 現金主義 | お金が動いた時   |
| 発生主義 | 取引が発生した時 |

## 6. 応用情報で特に狙われるところ

- 財務三表の関係
- 各種利益の意味
- 経営指標（ROE・自己資本比率など）
- 損益分岐点分析
- NPVなどの投資評価
