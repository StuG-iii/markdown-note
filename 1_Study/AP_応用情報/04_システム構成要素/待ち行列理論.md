# 待ち行列

## M/M/1モデルの特徴（条件）

- 客の頻度は**ランダム**　…**ポアソン分布**
- サービスにかかる時間は**ランダム** …**指数分布**
- （**1の行列に対して**）サービス提供窓口は**1つ**

## 平均到着率（λ）

単位時間あたりに到着する**平均の客の数**
例：
λ = 30人/時間
λ = 1/2人/分

## 平均到着間隔（1/λ）

客の到着する**平均の時間間隔**
例：
λ = 1/30時/人
λ = 2分/人

## 平均サービス率（μ）

単位時間あたりにサービスを提供できる**平均の人数（回数）**
μ = 40人/時
μ = 2/3人/分

## 平均サービス時間（1/μ）

1回のサービスにかかる平均の時間
1/μ = 1/40時/人
1/μ = 3/2分/人

## 利用率・占有率（ρ ロー）

サービス提供窓口が利用されている確率
ρ = λ/μ
ρ = 平均到着率/平均サービス率
例：
ρ = 30/40

※
1/μ / 1/λ = 平均サービス時間/平均到着間隔
例：
1.5/2 = 3/4

## 平均客数

ρ/1-p
利用率が高ければ高いほど平均客数も多くなる

例：
ρ = 0.5
0.5/1-0.5 = 1
50% 利用中 1人
50% 利用なし 0人
※ 利用率…先客（先にCPUを占有しているサービス）がいる確率、自分は含めない。

例：
ρ = 0.8 → 4
ρ = 0.9 → 9
ρ = 0.95 → 19
ρ = 1 → ∞
利用率が1に近づくにつれ指数関数的に増えていく。

## 平均待ち時間（Wq）

待ち行列に到着してからサービスを受けるまでの平均の時間

Wq = p/1-p *1/μ
Wq = 利用率* 平均サービス時間

## 平均応答時間（W）

待ち行列に到着してから、サービスを受け終わるまでの平均の時間

W = p/1-p * 1/μ + 1/μ
W = Wq + 1/μ
W = 平均待ち時間 + 平均サービス時間

平均待ち時間に対し自分の分のサービス時間を加えただけ

## 例題１

M/M/1の待ち行列モデルにおける、平均待ち時間（W）と窓口利用率（ρ）の関係で、
ρが0.25から0.75になったとき、Wは何倍になるか。

ρ = 0.25
0.25 / 1-0.25 = 0.25 / 0.75 = 1/3

ρ = 0.75
0.75 / 1-0.75 = 0.75 / 0.25 = 3

答え：9倍

## 例題２

コンピュータによる伝票処理システムがある。
このシステムは，伝票データをためる待ち行列をもち，M/M/1の待ち行列モデルが適用できるものとする。
平均待ち時間がT秒以上となるのは，処理装置の利用率が少なくとも何%以上となったときか。
ここで，伝票データをためる待ち行列の特徴は次のとおりである。

    伝票データは，ポアソン分布に従って到着する。
    伝票データをためる数に制限はない。
    1件の伝票データの処理時間は，平均T秒の指数分布に従う。

1/μ → T秒
W = ρ / 1-p * T ≧ T

代入：
ρ = 33% = 0.33
1/2T ≧ T → False

ρ = 50% = 0.5
1T ≧ T → True

答え：50%
