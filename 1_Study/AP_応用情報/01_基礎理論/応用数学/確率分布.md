## 期待値

長く続けたら、だいたいこの辺に落ち着く値

長期的に見たときの平均値
「1回ごとの結果」ではなく
何回も繰り返したときの中心

**例：**
サイコロ：出目：1〜6（各 1/6）
E(X) = (1+2+3+4+5+6)/6 = 3.5

---

## 分散

結果がどれくらい散らばるか
平均との差

**例：**

2つのゲームを比べる

ゲームA
結果：3 か 4 しか出ない

ゲームB
結果：1〜6 が出る

→ どっちが「荒れる」？
→ ゲームB

平均が同じでも
安定してるかバラバラかは違う。
この 荒れ具合を数値にしたのが **分散**。

---

## 標準偏差

分散を、人間が分かる大きさに戻したもの

σ = √Var(X)

分散は：ズレ² の平均
単位が変になる

例：
点数 → 分散は「点²」
→ 直感に合わない
→ 平方根で 元の感覚に戻す

---

## 正規分布

平均の周りに集まり、離れるほど起こりにくくなる分布

テストの点数・身長・誤差など、
自然に発生する多くの量がこの形になる。

形の特徴
- 山型（ベルカーブ）
- 左右対称
- 中央が一番出やすい
- 端はほぼ起きない（でもゼロではない）

| 記号        | 意味               |
| ----------- | ------------------ |
| μ（ミュー） | 平均（中心）       |
| σ（シグマ） | 標準偏差（広がり） |

### 68–95–99.7 の法則

| 範囲   | 含まれる割合 |
| ------ | ------------ |
| μ ± 1σ | 約68%        |
| μ ± 2σ | 約95%        |
| μ ± 3σ | 約99.7%      |

### 標準正規分布

定義
平均 μ = 0
標準偏差 σ = 1

Z = (X - μ) / σ
- X：元の値
- Z：標準化した値（何σ分ずれているか）
