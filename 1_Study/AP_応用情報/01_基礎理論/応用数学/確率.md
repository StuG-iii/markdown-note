## 場合の数

起こりうる全パターンの数を数えること

- 積の法則（かけ算）
  - 上：3通り
  - 下：2通り
   → 3 × 2 = 6通り
- 和の法則（たし算）
  - バスで行く：2通り
  - 電車で行く：3通り
   → 2 + 3 = 5通り

## 順列

順番が重要な選び方

3人から2人を並べる
A→B
B→A
別物

nPr = n! / (n−r)!
異なる n 個のものから r 個を選んで、並べる

### 公式の仕組み

**具体例：**
5人の中から3人選んで一列に並べる場合（5​P3​）

1. **1番目**に並ぶ人の選び方：**5通り**
2. **2番目**に並ぶ人の選び方：残りから選ぶので **4通り**
3. **3番目**に並ぶ人の選び方：さらに残りから選ぶので **3通り**

これを掛け合わせると5×4×3=60 通りとなる。

**公式との一致：**
この「5×4×3」を階乗（!）を使って表現すると、以下のようになる。
5×4×3×2×1 / 2×1 = 5! / 2!

**注意点：**
階乗（!）の計算: 0!=1 と定義される。
もし n=r（全員並べる）なら
n​Pn​ = n! / 0! = n!となる。

**組合せ（）との違い:**
「選ぶだけで並べない」のが組合せ。

## 組み合わせ

順番を気にしない選び方

AとBを選ぶ
A,B
B,A
→ 同じ

nCr = n! / (r!(n−r)!)
異なる n 個のものから r 個を、順番を気にせず選ぶ

### なぜ r! で割るのか？

**「選んだ r 個の並べ替えパターン（重複分）をすべて1つとして数える」**ための割り算

A, B, C の3人から2人選ぶ場合
- 順列（3​P2​）の場合: (A,B), (B,A), (A,C), (C,A), (B,C), (C,B) の 6通り。
- 組合せ（3​C2​）の場合: {A,B} と {B,A} は同じ「ペア」なので1通り。結果、3通り。

## 加法定理（どれかが起きる）

A または B が起きる確率P(A∪B)

**公式：**
P(A∪B)=P(A)+P(B)−P(A∩B)

**特殊ケース：**
互いに排反（同時に起こらない）
A と B が同時に起こり得ない（A∩B=∅）場合、単に足すだけになる。
P(A∪B)=P(A)+P(B)

---

## 乗法定理（両方起きる）

A が起きて、さらに B が起きる確率

**従属**（影響がある）
P(A∩B)=P(A)×P(B∣A)

- A が起きる
- A が起きた世界で B が起きる

**特殊ケース：**
独立（互いに影響しない）
P(A∩B)=P(A)×P(B)

A が起きても B に影響しない
条件付き確率が不要になる

---

## 条件付き確率（〜と分かったとき）

A が起きた世界に限定して
B が起きる割合

P(B∣A) = P(A∩B) / P(A)

全事象（分母）を「すべての可能性」から「事象 A の範囲内」に絞り込んだときの、B の割合

### 乗法定理との関係（密接）

→乗法定理は条件付き確率の公式を変形したもの
P(A∩B)=P(A)×P(B∣A)
（A が起こる確率に、「A が起きた後に B が起こる確率」を掛ける）
独立事象の場合は影響しない P(A∩B)=P(A)×P(B)

### 加法定理との関係

P(A∪B)=P(A)+P(B)−P(A∩B)
→ 条件付き確率を代入すると:
P(A∪B)=P(A)+P(B)−{P(A)×P(B∣A)}

---

## まとめ

| 問題文の表現    | 使う定理     |
| --------------- | ------------ |
| AまたはB        | 加法定理     |
| AかつB          | 乗法定理     |
| Bと分かったとき | 条件付き確率 |
| 同時に起きない  | 加法（排反） |
| 影響しない      | 乗法（独立） |
