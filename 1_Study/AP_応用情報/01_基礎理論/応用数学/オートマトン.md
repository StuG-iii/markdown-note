## 要約

「入力に応じて状態が遷移する仕組み」
＝ 状態遷移で振る舞いを表現する数学モデル
→ 「この文字列を受理するかどうかを判定する装置」

## 最小知識

| 要素         | 意味           |
| ------------ | -------------- |
| 状態集合     | 今どんな状況か |
| 入力記号集合 | 入力される文字 |
| 遷移関数     | どこへ移るか   |
| 初期状態     | スタート地点   |
| 受理状態     | ゴール（OK）   |

**順序機械**
1つの入力値によって1つの出力値が決まるのではなく，
入力値と入力されたときの状態によって出力値が決まる
 → 同じ入力でも
状態が違えば、出力も次の状態も変わる

## 有限オートマトン

### 要約（有限オートマトン）

有限個の状態を持ち、
入力を1文字ずつ読みながら状態遷移し、
最終的に受理するか否かを判定する仕組み

### 判定手順

手順
1. 初期状態からスタート
2. 入力文字列を左から1文字ずつ読む
3. 状態遷移を繰り返す
4. 最後に到達した状態が
    受理状態 → OK
    それ以外 → NG

### 備考

テキストの噛み砕き

・状態の有限集合 K = {a, b, c}
→ **内部状態は3種類しかない**
- a：まだ0を見ていない
- b：0を見たが、最後が0
- c：0を見て、最後が1（ゴール）

・入力記号の有限集合 Σ = {0, 1}
→ **入力は0か1しか来ない**

・状態遷移関数 δ
→ **「今の状態で、この入力が来たら、次はどこ？」のルール**

・初期状態 q₀ = a
→ **最初は必ず状態aから始まる**

・受理状態集合 F = {c}
→ **最後に c にいれば OK（受理）**

・状態遷移表（左）

| 今の状態 | 0   | 1   |
| -------- | --- | --- |
| a        | b   | a   |
| b        | b   | c   |
| c        | b   | c   |

> 状態aで0を読む → bへ
> 状態bで1を読む → cへ

・状態遷移図（右）
- ○：状態
- →：遷移
- 二重丸：受理状態（c）
**表を絵にしただけ**

## 正規表現

条件
「0を含み、1で終わる」
↓
(0|1)*0(0|1)*1

意味
- 0か1が何回でも
- どこかで0が出て
- 最後は1

有限オートマトンだと
a：まだ0を見ていない
b：0を見た
c：0を見て、最後が1（受理）
