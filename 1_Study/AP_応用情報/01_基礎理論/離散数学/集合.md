## 集合の基本

集合とは、ある条件を満たし、他のものとは明確に区別できるものの集まり。

集合の基本:
- **集合**： ある条件を満たす要素の集まり
  例：A = {1, 2, 3}
- **要素**： 集合を構成する個々の値
  1 ∈ A（1はAの要素）
- **部分集合**： B ⊆ A（Bの全要素がAに含まれる）
- **空集合**： ∅（要素を一つも持たない集合）
- **全体集合**： U（考察対象のすべて）

### 部分集合

集合 A と B について、

- B ⊆ A
  →「Bのすべての要素がAに含まれている」

※ **B = A も部分集合に含まれる**点が重要

---

### 真部分集合（⊂）

- **B ⊂ A**
  → B ⊆ A かつ B ≠ A
- 試験では

  - ⊆：等しい場合を含む
  - ⊂：等しい場合を含まない
    と区別されることがある（問題文をよく読む）

---

### 要素との違い（最重要）

- **1 ∈ A**
  → 1は「要素」
- **{1} ⊆ A**
  → {1}は「集合」

例：A = {1, 2, 3}

- 1 ⊆ A ❌（1は集合ではない）
- {1} ⊆ A ⭕

---

### 空集合と部分集合

- **∅ ⊆ A** は **常に真**
- 理由：
  「∅の要素すべてがAに含まれる」
  → ∅には要素がないので反例が存在しない

**補足**
反例探し
「∅ ⊆ A が偽になる」ためには、

- ∅ の中に
- A に含まれていない要素
- が **1つでも存在**しなければならない

でも：

- ∅ には要素が **1つも存在しない**

→ **反例を作れない＝常に真**

---

### 部分集合の個数（頻出計算）

集合Aの要素数を **n** とすると、

- **部分集合の総数 = 2ⁿ**

- 理由：

- 各要素を

  - 入れる
  - 入れない
    の2択で考える

例：

- A = {a, b, c}（n=3）
  → 2³ = 8個

---

### 応用情報らしい出題例

- 「次のうち部分集合でないものはどれか」
- 「真部分集合の個数を求めよ」
- 「∈ と ⊆ の誤用を指摘させる選択肢」

## べき集合

### 1. **べき集合**とは何か

集合 **A** に対して、

> **A のすべての部分集合を集めた集合**

これを **べき集合**といい、
**P(A)** または **𝒫(A)** と書く。

- **部分集合を全部集めた集合**
- **要素数は必ず 2ⁿ**
- **空集合と自分自身を必ず含む**

### 2. 具体例（超重要）

A = {a, b} の場合：

- 部分集合は
  ∅
  {a}
  {b}
  {a, b}

したがって：

- **P(A) = { ∅, {a}, {b}, {a, b} }**

→ ここでの注意

- **P(A) の要素は「集合」**
- a や b は **P(A) の要素ではない**

---

### 4. 個数の公式（最頻出）

A の要素数を **n** とすると：

- **|P(A)| = 2ⁿ**
※ | | → 要素数

理由：

- 各要素を

  - 入れる
  - 入れない
    の2択
- n個あれば 2 × 2 × … × 2 = 2ⁿ

例：

- |A| = 3 → |P(A)| = 8
- |A| = 0（空集合）→ |P(A)| = 1
  ※ P(∅) = {∅}

---

### 5. 試験で必ず狙われる罠

#### ① 要素と部分集合の混同

- a ∈ A ⭕
- {a} ⊆ A ⭕
- a ∈ P(A) ❌
- {a} ∈ P(A) ⭕

#### ② 空集合の扱い

- ∅ ⊆ A（常に真）
- **∅ ∈ P(A)**（必ず含まれる）

#### ③ 二段構えの集合

- P(A) の要素数を聞く
- さらに **P(P(A))** を聞く

例：

- |A| = 3
- |P(A)| = 8
- |P(P(A))| = 2⁸ = 256

---

## 1. 差集合（difference）

### 差集合の定義

- **A − B**（または A \ B）
- **「A に含まれていて、B には含まれていない要素」**

### 差集合図のイメージ

![Image](https://medium-company.com/wp-content/uploads/2020/10/sasyuugou.png)

![Image](https://www.math-only-math.com/images/difference-of-two-sets.png)

- 左の円 A のうち
- 右の円 B と重なっていない部分

### 例（差集合）

- A = {1,2,3}
- B = {3,4}

→ A − B = {1,2}

---

## 2. 対称差（symmetric difference）

### 対称差の定義

- **A △ B**
- **「A または B のどちらか一方にだけ含まれる要素」**

数式的には：

- **A △ B = (A − B) ∪ (B − A)**

### 対称差図のイメージ

![Image](https://upload.wikimedia.org/wikipedia/commons/6/6b/Venn-Diagram-XOR.png)

![Image](https://www.math-only-math.com/images/symmetric-difference-using-Venn-diagram.png)

- 両方に共通する部分（A ∩ B）を除いた左右の部分

### 例（対称差）

- A = {1,2,3}
- B = {3,4}

→ A △ B = {1,2,4}

---

## 3. 一目で分かる比較

| 演算  | 意味         | 共通部分 |
| ----- | ------------ | -------- |
| A − B | Aのみ        | 含まない |
| B − A | Bのみ        | 含まない |
| A △ B | どちらか一方 | 含まない |

---

## 4. 試験で狙われるポイント

### ① 引く向き

- A − B ≠ B − A
  ※ **順序に意味がある**

### ② 対称差は「OR ではない」

- 「A または B」だが
- **両方（AND）は除外**

### ③ 論理演算との対応

- 差集合：
  A − B → A ∧ ¬B
- 対称差：
  A △ B → (A ∧ ¬B) ∨ (¬A ∧ B)

---

### 応用情報向け暗記フレーズ

- **差集合：左だけ残す**
- **対称差：重なりを捨てる**
