以下では

- 論理：P, Q
- 集合：A, B
  を対応させています。

---

## 1. べき等則（同じものは変わらない）

### べき等則の形

- 論理

  - P ∨ P = P
  - P ∧ P = P
- 集合

  - A ∪ A = A
  - A ∩ A = A

### 見方

- 「同じ条件を何回言っても意味は同じ」
- 「同じ集合を足しても増えない」

👉 **重ねても変化しない**

---

## 2. 交換の法則（順番を入れ替えても同じ）

### 交換の法則の形

- 論理

  - P ∨ Q = Q ∨ P
  - P ∧ Q = Q ∧ P
- 集合

  - A ∪ B = B ∪ A
  - A ∩ B = B ∩ A

### 交換の法則の見方

- 「PとQの順番に意味はない」
- ベン図でも左右が入れ替わるだけ

👉 **左右入れ替えOK**

---

## 3. 結合の法則（まとめ方を変えても同じ）

### 結合の法則の形

- 論理

  - (P ∨ Q) ∨ R = P ∨ (Q ∨ R)
  - (P ∧ Q) ∧ R = P ∧ (Q ∧ R)
- 集合

  - (A ∪ B) ∪ C = A ∪ (B ∪ C)
  - (A ∩ B) ∩ C = A ∩ (B ∩ C)

### 結合の法則の見方

- 「どこから先に処理しても結果は同じ」
- 足し算・掛け算と同じ感覚

👉 **カッコの位置を気にしなくてよい**

---

## 4. 分配の法則（AND と OR が混ざる所）

### 分配の法則の形

- 論理

  - P ∧ (Q ∨ R) = (P ∧ Q) ∨ (P ∧ R)
  - P ∨ (Q ∧ R) = (P ∨ Q) ∧ (P ∨ R)
- 集合

  - A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  - A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

### 分配の法則の見方

- 「外側を中にばらまく」
- 因数分解・展開と同じ

👉 **1つずつ組み合わせる**

---

## 5. 吸収の法則（情報が冗長）

### 吸収の法則の形

- 論理

  - P ∨ (P ∧ Q) = P
  - P ∧ (P ∨ Q) = P
- 集合

  - A ∪ (A ∩ B) = A
  - A ∩ (A ∪ B) = A

### 吸収の法則の見方

- 「Pがある時点で、P＋αは意味がない」
- すでに含んでいる条件は無視される

👉 **大きい条件が小さい条件を吸収**

---

## 6. ド・モルガンの法則（否定の押し込み）

### ド・モルガンの法則の形

- 論理

  - ¬(P ∧ Q) = ¬P ∨ ¬Q
  - ¬(P ∨ Q) = ¬P ∧ ¬Q
- 集合

  - (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
  - (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ

### ド・モルガンの法則の見方

- 「否定が中に入ると AND / OR が反転」
- **全部ダメ → どれかダメ**
- **どれかOK → 全部ダメ**

👉 **否定＋反転**

---

## 7. その他（試験でよく使うもの）

### 否定の否定

- ¬(¬P) = P
- (Aᶜ)ᶜ = A

👉 **元に戻る**

---

### 恒真・恒偽

- 論理

  - P ∨ 真 = 真
  - P ∧ 偽 = 偽
- 集合

  - A ∪ U = U（全体集合）
  - A ∩ ∅ = ∅

👉 **強い方に引っ張られる**

---

## 一気に覚える試験用まとめ

- **∨ / ∪**：足す・広げる
- **∧ / ∩**：絞る・重なる
- **¬ / ᶜ**：外に出す
- **ド・モルガン**：否定＋反転
- **吸収**：同じものがあれば削る
