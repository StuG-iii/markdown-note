# パリティチェック

送るデータ：
1011001

パリティビット=0
10110010

受信側
- 1の個数が偶数か確認
- 崩れていれば誤り検出

## 特徴

- 1ビット誤りは検出可能
- 訂正不可

## 注意点

- 偶数個の誤り → 検出できない
- バースト誤り（連続誤り）に弱い

# CRC

## 要約

CRCとは：
ビット列を「多項式」とみなして割り算をし、
余りを検査用データとして付加する
強力な誤り検出方式

## 最小知識

- バースト誤り（連続誤り）に強い

## 注意点

- 訂正はしない

## 備考

CRCの割り算は
**XOR（排他的論理和）**による割り算

# 水平垂直パリティチェック

## 要約

データを2次元（表）に並べ、
行方向と列方向の両方に
パリティを付ける誤り検出方式

## 最小知識

**単純パリティの弱点**
- 偶数個の誤り → 検出できない
- どこが壊れたか分からない

**水平垂直パリティの狙い**
- 誤り検出能力を強化
- 1ビット誤りなら位置まで分かる

**イメージ**
             列P
    1 0 1 0 | P
    0 1 0 1 | P
    1 1 0 0 | P
    ----------
行P  P P P P

# ハミング符号

## 要約

ハミング符号とは：
最小限の冗長ビットで
1ビット誤りを検出・訂正できる方式

## 最小知識

| 内容       | 可否 |
| -------- | -- |
| 1ビット誤り検出 | ○  |
| 1ビット誤り訂正 | ○  |
| 2ビット誤り検出 | ○  |
| 2ビット誤り訂正 | ×  |

2のべき乗にパリティを置く
位置: 1 2 3 4 5 6 7
内容: P P D P D D D

ハミング符号の誤り判定
1. すべての式の値が0 → ビット誤りなし
P1 = 0
P2 = 0
P4 = 0

2. 1つの式のみ値が1 → その式に含まれるビットに誤りあり
P1 = 1
P2 = 0
P4 = 0

3. 複数の式の値が1 → 共通して含まれるビットに誤りあり
P1 = 1
P2 = 1
P4 = 0
