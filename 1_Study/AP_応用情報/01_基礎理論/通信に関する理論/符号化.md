# 符号化

## 要約

**情報（記号）を0と1の列に割り当てること**
平均ビット数をできるだけエントロピーに近づける。

## 最小知識

- 4文字を符号化する場合1文字当たり2ビットあれば一意に識別できるが、各文字の出現確率が異なるときは、1文字当たり平均2ビットより少ないビット数で表現できる。
- 情報符号化の代表的な方法
  - ハフマン符号化
  - ランレングス符号化
- エントロピー ≤ 平均符号長 < エントロピー + 1

### 固定長符号

出現確率が一定なら良いが、偏りがあるなら無駄がある。

| 記号 | 符号 |
| ---- | ---- |
| A    | 00   |
| B    | 01   |
| C    | 10   |
| D    | 11   |

### 可変長符号

出現確率に応じて割り当てるビット数を変える。

| 記号 | 符号 |
| ---- | ---- |
| A    | 0    |
| B    | 10   |
| C    | 110  |
| D    | 111  |

# ハフマン符号化

## 要約

出現確率が分かっている記号に対して、
平均符号長が最小になるように作る
可変長・接頭語自由な符号。

## 作り方

- 確率が一番小さい2つを選ぶ
- それらを「まとめて1つ」にする
- 確率を足す
- これを1つになるまで繰り返す
- 枝に 0 / 1 を割り当てる

## 具体例

| 記号 | 確率 |
| ---- | ---- |
| A    | 0.4  |
| B    | 0.3  |
| C    | 0.2  |
| D    | 0.1  |

        (1.0)
       /     \
    A(0.4)  (0.6)
            /   \
        B(0.3)  (0.3)
                /   \
            C(0.2)  D(0.1)

左=0 右=1

| 記号 | 符号 |
| ---- | ---- |
| A    | 0    |
| B    | 10   |
| C    | 110  |
| D    | 111  |

## 平均符号長

L = 0.4×1 + 0.3×2 + 0.2×3 + 0.1×3
  = 1.9 bit

# ランレングス符号化

## 要約

同じ記号が連続している部分（ラン）を
「記号＋連続回数」でまとめて表す符号化。

## 最小知識

AAAAABBBBCCDAA
↓
(A,5)(B,4)(C,2)(D,1)(A,2)

## 注意点

ハフマン符号化との違い

| 観点         | ハフマン符号 | ランレングス符号 |
| ------------ | ------------ | ---------------- |
| 利用する情報 | 出現確率     | 連続性           |
| 符号長       | 可変         | 回数で表現       |
| 順序依存     | しない       | **する**         |
| 効果         | 全体平均     | **局所的**       |

駄目な例
0101010101010101
↓
(0,1)(1,1)(0,1)(1,1)...
