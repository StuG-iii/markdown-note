## 文脈自由文法（形式文法）

入れ子構造（対応関係）を持つ文字列を定義できる文法

| 要素   | 意味                   |
| ------ | ---------------------- |
| V or N | 非終端記号（変数）     |
| Σ or T | 終端記号（実際の文字） |
| P      | 生成規則               |
| S      | 開始記号               |

---

## BNF記法

「非終端記号を右辺で展開していく規則」を統一表記で書く方法
CFGの中身（生成規則）を見やすくしただけ

**例：**

<非終端記号> ::= 定義

- ::= ：「定義する」「置き換える」
- < > ：非終端記号（変数）
- 右辺：終端記号と非終端記号の並び
- | ：「または」

例：0と1の列

```
<bin> ::= 0 | 1 | <bin><bin>

意味：
<bin> は
0 か
1 か
<bin>を2つ並べたもの
```
