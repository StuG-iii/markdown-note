# 変更の取消

## ファイルへの変更を取り消す

`git checkout --<ファイル名`
`git checkout --<ディレクトリ名`

### 全変更と取り消す

`git checkout -- .`

### 備考：現在の推奨

`git restore`
`git checkout`はブランチ切り替えの役割もあり、混乱を招くため。

## ステージした変更を取り消す

`git reset HEAD <ファイル名`
`git reset HEAD <ディレクトリ名`

### 全変更を取り消す

`git reset HEAD .`

### 直前のコミットを修正する

`git commit --amend`

### 注意点

リモートリポジトリにPushしたコミットにやってはいけない、ユーザによって履歴が変わってしまう。

一度コミットした場合は再度コミットし直す。

最初のコミットを取り消す場合のみ挙動が変わり、必要なコマンドが違う。

### コミット取り消し（最初）

`git update-ref -d HEAD`

消えたか確認
`git log`

### add取り消し（最初）

`git rm --cached -r .`
