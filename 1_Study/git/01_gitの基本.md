# gitの基本

## ローカルの3つのエリア

1. ワークツリー
2. ステージ
3. リポジトリ

### リポジトリ

スナップショットを記録

以下のファイルを作成することでデータを保存

- 圧縮ファイル
  - 圧縮されたファイル
  - git addで作成
- ツリー
  - ファイル名と圧縮ファイル（ハッシュ名）の紐づけ
  - git addで作成
- コミット
  - 以下の情報を持つ
    - ツリーとの紐づけ
    - 親コミット
    - 作成者
    - 日付
    - コミットメッセージ
  - git commitで作成

### ステージ

コミットする変更を準備

インデックス:

- ファイル名と圧縮ファイル（ハッシュ名）の紐づけ
- リポジトリのツリーとの違いは一つのファイルにデータを纏めている。
- `git add`で更新

### ワークツリー

ファイルを変更する作業上
