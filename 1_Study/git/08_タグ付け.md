# タグ付け

## タグの一覧を表示する

`git tag`

### パターンを指定してタグを表示

`git tag -l "201705"`
20170501_01
20170501_02
20170503_01

## タグを作成する

### 注釈付きタグ

`git tag -a <タグ名> -m "メッセージ"`
`git tag -a 20170520_01 -m "メッセージ" -m "version 20170520_01"`

`-a`（Annotation） オプションを付けると注釈付きタグを作成する
`-m` オプションを付けるとエディタを立ち上げずメッセージを入力

### 軽量版タグ

`git tag -a <タグ名>`
`git tag -a 20170520_01`

### 後からタグ付けする

`git tag <タグ名> <コミット名>`
`git tag 20170520_01 8a6cbc4`

## タグのデータを表示する

`git show <タグ名>`
`git show 20170520_01`

## タグをリモートリポジトリに送信する

`git push <リモート名> <タグ名>`
`git push origin 20170520_01`

### タグを一斉に送信する

`git push origin --tags`
