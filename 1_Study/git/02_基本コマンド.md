# 基本コマンド

## git init

`git init`
gitリポジトリの新規作成
.gitフォルダが作成される

.git内のデータ
- objects
  - リポジトリの本体
  - 圧縮ファイル、ツリーファイル、コミットファイルが保存されている
- config
  - gitの設定ファイル

## git clone

`git clone <リポジトリ名>`（例：githubのプロジェクトURL）
git hub上などで公開されているリモートリポジトリからソースコードをコピーできる

## git add

ステージへの追加
`git add` <ファイル名>
`git add <ディレクトリ名>`
`git add .`（現在地の全てのファイル）

## git commit

ステージへの変更内容をスナップショットとしてリポジトリに記録する
- `git commit`
- `it commit -m "<メッセージ>"`
- メッセージ付きで記録
- `git commit -v`
  - 変更内容を事前確認

**メッセージの書き方**
1行目：変更内容の要約
2行目：空行
3行目：変更した理由

## git status

変更されたファイルの確認
`git status`

## git diff

ファイルの変更差分を確認

### git addする前の変更分

- `git diff`
- `git diff <ファイル名>`

### git addした後の変更分

`git diff --staged`

## git log

変更履歴を確認する
`git log`

### 一行で表示する

`git log --oneline`

### ファイルの変更差分を表示ｓるう

`git log -p index.html`

### 表示するコミット数を制限する

`git log -n <コミット数>`

## ファイル削除

`git rm`
ファイルの削除を記録する

### ファイルごと削除

`git rm <ファイル名>`
`git rm -r <ディレクトリ名>`

### ファイルをワークツリーに残したいとき

`git rm --cached <ファイル名>`

## ファイル名変更

`git mv <旧ファイル名> <新ファイル名>`

### 上記は以下コマンドと同じ

1. `mv <旧ファイル名> <新ファイル名>`
2. `git rm <旧ファイル名>`
3. `git add <新ファイル名>`

## git push

`git push`
リモートリポジトリにローカルの内容をアップすること

### ローカルにリモートリポジトリを新規追加

`git remote add origin <gitURL>`
名前を登録しておけばGitHubとのやり取りでURLを省略できる

`origin`
gitの慣用句、メインのリポートリポジトリにoriginと付けるのが普通。

### リモートリポジトリ（GitHub）へ送信する

- `git push <リモート名> <ブランチ名>`
- `git push origin master`

**master**
デフォルトのブランチ名

### GitHubとの連携方法

1. GitHubを開く
2. メニューからSettings
3. Developer Settings
4. Personal access tokens
5. Generate new toke
6. 設定を入力して確定
7. アクセストークンをコピーして保存する

### GitHubでリポジトリを作成

1. Repositories
2. New
3. 入力して確定
4. ローカルでコマンド `git remote add origin <リポジトリurl>`
5. 認証

## git config

コンフィグの設定
エイリアスなど設定できる

### エイリアス

`git config --global alias.ci commit`
ciがcommitの役割を持つ

## 管理しないファイルをGitの管理から外す方法

`.gitignore`をテキストで作成

### 記入例

- 指定したファイルを除外
  - `index.html`
- ルートディレクトリを指定
  - `/root.html`
- ディレクトリ以下を除外
  - `dir/`
- /以外の文字列にマッチ「*」
  - `/*/.css`
