### 76

販売単価と固定費が変わったあと、今年と同じ営業利益を出すには何台売ればいいか

#### 今年度

| 項目     |          値 |
| -------- | ----------: |
| 販売台数 |     2,500台 |
| 販売単価 |     200千円 |
| 固定費   | 150,000千円 |
| 変動費   |  100千円/台 |

#### 今年いくら利益が出ているか

```
1台売ると、
200-100=100千円=1台あたりの限界利益
したがって、2,500台得れば、
100*2500=250,000千円
ここから固定費150,000千円を引くので、
250,000-150,000=100,000千円=今年度の営業利益
```

#### 来年度はどうなるか

```
販売単価は5%低下するので、
200*0.95=190千円
固定費は5%増加するので、
150,000*1.05=157,500千円
変動費は問題文では変化しないので、
100千円/台
したがって来年度の1台当たり限界利益は、
190-100=90千円

1台売る
→ 売上 190千円
→ 変動費 100千円
→ 90千円残る

その90千円の積み重ねから
固定費157,500千円を払い、

さらに今年と同じ利益
100,000千円を残したい
```

#### 利益100,000千円残すには

```
売上台数を x とすると、
90x-157,500=100,000
90=257,500
x=257,500/90
x=2861.1=2862台
```

### 77

損益分岐点売上高を求める

| 項目             | 金額（百万円） |
| ---------------- | -------------: |
| 売上高           |            500 |
| 材料費（変動費） |            200 |
| 外注費（変動費） |            100 |
| 製造固定費       |            100 |
| 総利益           |            100 |
| 販売固定費       |             80 |
| 利益             |             20 |

```
変動費=200+100=300
固定費=100+80=180
変動費率＝変動費/売上高=300/500=0.6
つまり、売上100円のうち60円が変動費として消える。
残るのは、
1-0.6=0.4=固定費を回収するために使える部分
```

#### 損益分岐点

損益分岐点とは、*利益がちょうど0になる売上高*

固定費は180百万円あるので、売上の40%を積み上げて、180百万円をちょうど回収できればよい。

損益分岐点売上高=180/0.4=450百万円

#### なぜ固定費を0.4で割るのか

売上が100万円増えても、全部が固定費回収に使えるわけではない。

```
売上100万円
├─ 変動費 60万円
└─ 残り   40万円 ← 固定費回収・利益に使える
```

だから固定費180百万円を回収するには、

180/0.4=450百万円

#### まとめ

変動費率＝変動費/売上高

限界利益率 = 1-変動費率

損益分岐点売上高=固定費/限界利益率
