## 午後試験を解く手順例

1. 問いを確認する：対象・問われ方・制約を確認する
   1. 対象 例：サーバAのことか、システム全体のことか
   2. 問われ方 …原因・目的・対策・リスクのどれか
   3. 制約 …40文字以内、2つ答える、本文中の字句を使う、など
   4. **次の手順へ**：「失敗してもログを残す対策を、40字以内で答える」と分かる
2. 解くための材料探し：答案の根拠を探す
   1. 場所を探す …指定された本文・図・表を見る
      1. 次へ 不具合の説明と処理の図にたどり着く
   2. 事実を取り出す …関係する記述や処理を一つ確認する
      1. 次へ 「ログを記録した後にロールバックする」と分かる
   3. 知識を確認する …その事実を考えるための知識を思い出す
      1. 次へ 「ロールバックは、そのトランザクションの更新を取り消す」と分かる
   4. 結び付けて考える …事実と知識を組み合わせる
      1. 次へ 「ログの記録も取り消される」と分かる
3. 答案を作る：問われた内容に合わせて答える
   1. 原因・理由 …何が、どのように結果を引き起こすか
   2. 目的 …何を実現・防止したいのか
   3. 対策 …何を、どう変更・実施するのか
   4. リスク …どのような望ましくないことが起こり得るか
4. 確認する：設問の要求・本文の条件と照合する
   1. 完了 …対策として成立し、字数などの指定も満たしている

## 復習方法

| 間違えた原因               | 次にすること                                         |
| -------------------------- | ---------------------------------------------------- |
| 必要な知識がなかった       | 教本の該当箇所を確認し、仕組みを説明できるようにする |
| 本文の条件を見落とした     | 解答の根拠になった一文・図表を特定する               |
| 設問の要求を取り違えた     | 「誰の・何について・何を答えるか」を短く言い直す     |
| 分かっていたが書けなかった | 必要な要素を確認し、字数内で答案を書き直す           |
