## 分子・分母の決め方

調べたい量 / 基準となる量

「基準となる○○に対して、△△はどれくらい？」
→ △△ / ○○

### よくある日本語 → 割り算

| 問題文の意味                     | 式          |
| -------------------------------- | ----------- |
| 全体のうち、○○はどれくらい？     | ○○ ÷ 全体   |
| Aに対してBはどれくらい？         | B ÷ A       |
| A 1個当たりBはいくら？           | B ÷ Aの個数 |
| Aを使ってBをどれだけ生み出した？ | B ÷ A       |
| 1秒当たり何個？                  | 個数 ÷ 秒   |
| 1個当たり何秒？                  | 秒 ÷ 個数   |
|                                  |             |

つまり、「～に対して」「～あたり」の後ろ側が分子、基準側分母と考える

売上高営業利益率
→ 売上に対して利益は？
→ 利益 ÷ 売上

総資産営業利益率
→ 資産に対して利益は？
→ 利益 ÷ 資産

総資産回転率
→ 資産に対して売上は？
→ 売上 ÷ 資産

### 率とはそもそもなにか？

ある量を、基準となる量で割って比較しやすくなったもの

たとえば100個の製品のうち5個が不良品なら、

不良率 = 不良品5個 / 全体100個 = 5%

ここで大事なのは、
- 基準：全部で100個
- 注目しているもの：不良品5個
という関係。

率 = 注目している量 / 基準となる量

### なぜ「率」にするのか

例えば、
- A工場では不良品が10個出た
- B工場では不良品が20個出た

だけでは、B工場の方が悪いとは限らない。
A工場が100個作って10個不良なら、
→ 10/100 = 10%

B工場が1000個作って20個不良なら、
→ 20/1000 = 2%

つまり、「率」を使う目的は、**規模が違うもの同士を公平に比較する**ため。
